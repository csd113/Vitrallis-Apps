# Firefly Field

Firefly Field is a quiet, fullscreen nighttime meadow for Vitrallis. Original
pixel-art layers, distant silhouettes, swaying foreground grass, occasional
shooting stars and independently blinking fireflies create an ambient scene
without network, audio or persistent storage.

## Rendering

The app uses the system SDL2 library through a deliberately small `ctypes`
binding; it has no pip dependencies. Its renderer policy follows the
`GPU-HW-ACCELERATION` Vitrallis Shell branch: it enumerates SDL drivers, prefers
an advertised `opengles2` accelerated backend, retries every accelerated backend
without vsync if necessary, verifies the resulting flags, and then falls back to
a fresh SDL software renderer for `auto`. `--renderer hardware` refuses to run
without verified acceleration; `--renderer software` skips GPU attempts.

It uploads a background, radial glow, firefly sprite and grass texture once,
then renders them with `SDL_RenderCopyEx`, alpha modulation and additive glow
every frame. The startup diagnostic uses Shell's
`event=renderer_initialized` shape and reports requested/actual mode, backend,
flags, dimensions and any automatic fallback reason. Acceleration flags alone
do not prove a physical GPU is rendering; validate the target driver separately.

This catalog currently documents Tkinter and an optional EGL/GLES2 demo, not a
shared SDL wrapper. Firefly Field consequently owns its SDL lifecycle rather
than claiming an unavailable Vitrallis SDL API. It requires Python 3.8+ and a
system SDL2 2.0+ video driver; hardware behavior must still be verified on the
target PocketCHIP/Shell build before publication as installable.

Run from any directory:

```sh
python3 /path/to/apps/firefly-field/main.py
python3 /path/to/apps/firefly-field/main.py --windowed
python3 /path/to/apps/firefly-field/main.py --renderer hardware
python3 /path/to/apps/firefly-field/main.py --renderer software --windowed
python3 /path/to/apps/firefly-field/main.py --check
```

## Controls

| Input | Effect |
| --- | --- |
| Pointer/finger | Nearby insects give the pointer room. |
| Click/tap | Briefly scatters nearby insects. |
| Space | Pause or resume. |
| R | Reseed the field. |
| H | Toggle the status overlay. |
| Up / Down | Add or remove 10 fireflies. |
| Left / Right | Reduce or increase glow. |
| Escape | Exit through the normal window lifecycle. |

The default view intentionally has no visible UI. The optional overlay reports
population, measured frame rate and SDL renderer name.

## Artwork and performance

All artwork is original and local to this package. Static scene and reusable
sprite pixel data are created once at startup and transferred to SDL textures;
per-frame CPU work is restricted to insect movement, blink state and a small
amount of control logic. The app does not use an animated CPU image, Pillow or
a full-frame texture upload. The package icon is generated by
`assets/make_icon.py` using only the standard library.

Desktop tests do not certify SDL driver selection, fullscreen behavior, touch,
GPU performance or App Center installation on physical hardware.
