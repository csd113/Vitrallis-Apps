# Artwork

`dashboard.png` is the original version 1.0.0 PocketCHIP screenshot from
[PocketChip-Bitcoin-Display](https://github.com/csd113/PocketChip-Bitcoin-Display).
It documents the dashboard's visual identity; it is not loaded at runtime.

The package-root `icon.png` is an original 128×128 pixel drawing created for this
native package: a white Bitcoin letter on an orange coin, using the dashboard's
orange and dark background colors. It contains no third-party artwork.
