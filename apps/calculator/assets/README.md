# Calculator artwork

The App Center loads the package-root `icon.png`. Runtime artwork must stay small,
with transparent margins and a recognizable silhouette at 32 pixels.

The icon was generated with OpenAI built-in image generation on 2026-10-01,
then cropped to alpha bounds and scaled to a 108-pixel mark on transparent
128×128. The full prompt and retained-art audit are in repository `docs/artwork.md`.
