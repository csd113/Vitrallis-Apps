# Vitrallis Debug assets

`icon.png` is original artwork created for this package: a hand-drawn, raster
diagnostic chip with a pulse trace. The live dashboard uses only Tkinter Canvas
primitives and needs no additional runtime artwork.

No external artwork, fonts, network resources, or generated media are used.

The root icon was replaced on 2026-10-01 with OpenAI built-in image generation,
then alpha-preserving scaled to 128×128. The original runtime sprites are unchanged.
See `docs/artwork.md` in the repository for the audit, prompts and processing.
