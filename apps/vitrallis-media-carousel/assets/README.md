# Original artwork

`icon.svg` is original geometric artwork created for this app: overlapping photo
cards and a next/play arrow. `../icon.png` is its 128×128 raster rendition.
Reproduce it with `python3 tests/make_icon.py`. No third-party artwork is included.
Repository licensing remains an owner decision; no license is assumed here.

`capability-vp8.webm`, `capability-vp9.webm` and `capability.webp` are original 16×16 solid-red test images generated for real decoder capability checks. They contain no user media or external content.
